# 本轮安全核验摘要

范围为在用的 Ziokt Python 入口、原生提供者同步代码、应用路由、ETP 适配器、SIM/WATChat 网关与 Engine Zero 奋斗页。采用差异审查、危险 API 搜索、依赖告警查询、临时链与实际浏览器测试；不声称已证明不存在任何漏洞。

| 边界 | 已执行的控制与核验 |
|---|---|
| 原生调用到组件 | 私有配置指定后端路径、组件身份、方法白名单；两个真实 CLI 各调用全部 11 个目标；越权方法与错误身份被拒绝 |
| ETP 文件到进程 | 摘要锁定、拒绝组/其它用户可写文件，执行已核验字节的私有副本；在启动前替换原文件的测试仍运行已核验版本；四个真实网关完成多跳 AEAD 收发 |
| 公网到本机链权限 | 仅获取 Engine Zero 任务和提交 nonce；验证来源、长度、任务寿命、范围、网络、当前区块与节点身份；并发和请求预算有限；不能从浏览器指定任意引擎、地址或命令 |
| 重试到原生交易 | 固定每个问题的 operation ID，先持久化意图，再执行 commit；未知结果使用 reconcile；真实临时链测试确认重复提交只留一条交易 |
| 设备资源到计算 | 页面明确说明 CPU、电量和贡献归属；实际浏览器验证点击前无任务、SHA-256 证明、停止与后台终止；不在页面加载时运行计算 |
| SIM 计划到通知 | 私有应用密钥封装计划，签名联邦文件传递；已有账户的网关拉取后实际调度；持久重试与并发编辑测试通过；新到期时间重置发送状态 |
| 匿名慢链路 | 固定证书的 mTLS 身份获得有界的分片读取时间；保留 30 秒授权窗口和防重放；超时响应保留填充并返回可重试错误 |
| 在线到 AirGap | 进程启动策略阻断 DNS、socket、代理、子进程与原生网关；保留离线计算及签名密文文件交换；不代表物理隔离或 OS 沙箱 |

在用的 WATChat、SIM Manager、Tri、浏览器 CI 四个 npm 锁定依赖树审计均为零告警；在用 ETP Cargo.lock 的开放 Dependabot 告警为零。这不代表整个源码仓库零告警：检查时仍有 37 条告警落在 `companions/*/original/` 的历史参考清单，保留的原始实现不作为现代运行入口。发布包保留这些参考源码，部署应使用本文档列出的在用入口。

匿名中继不拥有内容密钥，但邻接地址、时间、流量长度桶和公开收藏件链仍可观察；不宣称抵御全局观察者的数学证明。通知真实手机送达、公网 TLS/DNS 实际部署尚未在目标环境执行。部分原始 ETP 可选绑定未提供实现，选择时明确失败，不列为已可用功能。具体构建配置、结果和来源见 `verification-current.json`。
