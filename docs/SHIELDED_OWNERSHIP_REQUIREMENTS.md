# ZKN 屏蔽所有权：尚未满足的共识条件

当前原生 `zkn_private_transfer` 的 token ID、nonce、recipient 和交易公钥属于可观察事实。界面脱敏、固定封装、Tor、I2P、2–4 跳代理均不能消除该账本事实。现有交易不得通过 GUI 隐藏显示后被称为匿名。

真正屏蔽所有权需要独立的版本化共识升级：承诺树与隐藏所有者的 note、链域隔离的 nullifier、已审计的成员/所有权/守恒证明验证器、一次性收款地址、定长加密 note、重组一致性、双花与 mempool 冲突处理、钱包扫描与恢复、可选披露，以及透明资产进入/退出隐私池的显式迁移。验证器和证明参数必须固定摘要；未知证明版本及未配置验证器必须拒绝。

应先在隔离测试链完成旧交易兼容、重复 nullifier、无效证明、状态回滚、链重组、跨网络重放、钱包恢复、观察者关联分析和负载验证，再由节点所有者决定升级窗口。不得用自制未经审计的密码学或静默改写已有主网 ownership 字段替代这些条件。

本批实现没有声称此共识升级已经完成。现有真实能力与缺口通过 `ziokt_privacy_status` 暴露，防止客户端或模型将封装隐私误报成链上匿名性。
