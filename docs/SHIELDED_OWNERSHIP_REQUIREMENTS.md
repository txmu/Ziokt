# ZKN 屏蔽所有权：尚未满足的共识条件

当前原生 `zkn_private_transfer` 的 token ID、nonce、recipient 和交易公钥属于可观察事实。界面脱敏、固定封装、Tor、I2P、2–4 跳代理均不能消除该账本事实。现有交易不得通过 GUI 隐藏显示后被称为匿名。

真正屏蔽所有权需要独立的版本化共识升级：承诺树与隐藏所有者的 note、链域隔离的 nullifier、已审计的成员/所有权/守恒证明验证器、一次性收款地址、定长加密 note、重组一致性、双花与 mempool 冲突处理、钱包扫描与恢复、可选披露，以及透明资产进入/退出隐私池的显式迁移。验证器和证明参数必须固定摘要；未知证明版本及未配置验证器必须拒绝。

应先在隔离测试链完成旧交易兼容、重复 nullifier、无效证明、状态回滚、链重组、跨网络重放、钱包恢复、观察者关联分析和负载验证，再由节点所有者决定升级窗口。不得用自制未经审计的密码学或静默改写已有主网 ownership 字段替代这些条件。

本批实现没有声称此共识升级已经完成。现有真实能力与缺口通过 `ziokt_privacy_status` 暴露，防止客户端或模型将封装隐私误报成链上匿名性。

## 原生链验收与主网边界（2026-10-19）

`tests/test_native_shielded.py` 将测试网原生区块打包、快照 NFT 铸造、16 个真实资产入池、环证明转移、待确认和已确认双花拒绝、退出到透明所有者及派生状态重建串成同一条验收链路。资产和 note 不通过测试 SQL 直接插入；外层转移与退出使用钱包新生成的 secp256k1 签名身份。此测试加入 `privacy-naming.yml`，与已有伪造证明、网络重放、重组回滚和自愿披露测试一起运行。

另一个原生准入测试覆盖 `ziokt-main` 的三种屏蔽交易，检查拒绝后区块、交易池和屏蔽表没有变化。该测试确认当前主网限制有效，不代表主网已启用匿名转移。

现有协议是未经独立审计的实验性 Ristretto 环签名方案。完整功能测试不能代替密码学审计，也不能证明抵抗全局时序关联。透明入池与退出仍然可观察；少量或可识别的环成员可能缩小实际匿名集合。

主网激活仍须落实独立密码学审计及修复、可重复的协议与验证器版本固定、所有验证节点一致的激活高度及升级规则、升级前后历史重放验收，以及钱包扫描恢复、匿名集合关联分析和负载验收。没有这些证据时，不应更改 `ZS_AUDITED`、删除 `zs_testnet` 限制、重命名生产网络为测试网络，或改写既有所有权以宣称完成主网匿名化。审查请求及自愿披露可独立运行；投票通过不会产生通用解密能力。

后续准入修复、本地加密钱包恢复、公开 key image 查询与新增回归范围见 [本轮检查与使用说明](PRIVACY_HARDENING_2026-10-19_ZH.md)。局部恢复能力已经实现，不代表上述全部主网验收条件完成。
