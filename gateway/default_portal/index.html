Cor-Web 原生去中心化全景门户

本页面通过 Corium NNS 域名系统与 DHT 分布式对象网络托管。无中心化服务器、纯净安全且全网防篡改，直接驱动生态全量 DApp。

💡 什么是 Cor-Web？
Cor-Web 是 Corium 与 Ziokt 架构中的原生 Web 体系。网页全部以密码学分块散列形式存储于 P2P 网络，经由 NNS 解析直接挂载到网关；所有动态交互均运行在受控双层沙箱中，消除了跨站脚本 (XSS) 与第三方中间人劫持风险。

• DUAL-MODE UI 界面双模体系: 支持 全景版 (深度交互工坊/仿真器/微架构追踪) 与 简约版 (极简视窗/高密度/极速渲染)，顶部工具栏一键无缝热切换。
• CRYPTO BOUNDARY 端侧密码学签名: 浏览器非导出 WebCrypto Ed25519 私钥存入 IndexedDB 独立保险库，发布论坛/动态直接签名，节点私钥绝对零暴露。
• ZERO-COPY STREAM 零拷贝媒体直通: /stream/<root> 路由搭载原生 HTTP Range 流媒体引擎，免落盘边下边播。
• MCP AGENT PROTOCOL 模型上下文协议: 2026 原生规范，支持 OAuth2 PKCE 授权接入、跨组件工具动态探测与写前计划审查确认。
