# Ziokt 助力 Windows 客户端

Windows 10/11 x64 用户开发包，未做 Authenticode 签名；系统可能显示未知发布者提示。安装前核对 SHA256SUMS 和 build-source.json。MSI 安装到当前用户的 LocalAppData，无需管理员权限；EXE 也可直接运行。运行需要 Microsoft Edge WebView2 Runtime，缺少时程序询问是否打开微软官方下载页，不静默安装组件。

选择轻量网络协作或计算协作，然后点击“一键启用（后台继续）”。实际任务、传输结果和原生回执显示在官方奋斗页，未领取任务不代表已经贡献，也不承诺收益。轻量网络协作默认使用运营者配置的主网直连任务；如服务端没有可用任务，显示等待，不伪造流量或奖励。主网直连不是匿名传输。高级参与码维持原有受限转发接口。

关闭窗口会保留系统托盘，可双击打开。托盘提供停止和退出；程序不阻止 Windows 休眠、不申请系统服务权限、不隐藏自身、不反复重新启动自己。用户可主动勾选“登录时启动并恢复上次助力”，写入当前用户 HKCU Run；取消勾选即移除。安装过程默认不设置自启。卸载也移除该项；用户设置保留于 LocalAppData/ZioktEffort/preferences.json，可自行删除。

断网时通过 Windows NetworkAvailabilityChanged 通知暂停，恢复时继续之前主动启用的任务；手动停止取消恢复。没有定时连通性探测、Ping 或探测网址。系统事件表示网络接口可用，并不证明互联网或某个服务器可达；实际业务失败由业务请求显示。程序不修改 VPN/Tor/I2P 策略、不为其他应用启用直连回退。

主页面限定 HTTPS fendou.ziokt.com，禁止下载和页面原生权限，外部 HTTPS 链接交由系统浏览器打开；应用无 Gateway 管理员凭证、钱包或私钥。浏览器数据使用独立用户目录，不共享用户已有浏览器会话。

CI 在真实 Windows Runner 上编译独立 EXE，运行入口安全检查，并安装、卸载 MSI。Windows 实体设备、长时间后台运行、休眠恢复和用户设备上的网络切换仍需验收；CI 运行 ID 和源码提交写入 build-source.json。完整生态验收不随此包发布而自动完成。

OpenCI 第三模式支持接入审批、按实际设备/节点架构领取预处理 C 编译任务、受限 WASM 对象编译和 Ed25519 产物提交。可显式选择 HTTPS 节点。Android 第三模式使用独立进程的系统 WebView，前两种模式保持 Java 原生；前台编译停止后不暗中转入其他模式。私有 Worker 凭证须单独保存，不能填写钱包密钥。网络互助回执需经独立 peer 见证才可记入 ZKT 本地声誉，不代表主链代币结算。
