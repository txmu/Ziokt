# Ziokt 轻量助力 · Android

纯 Java 原生程序，不捆绑浏览器/WebView、.NET、Python、地图或原生计算库。一个 universal APK 支持 Android 9（API 28）及以后、ARM 32 位和 ARM64。没有 JNI `.so`，因此不依赖特定 ARM ABI；实体 ARM 设备仍需单独验收。

目标设备为 2 核、2 GB RAM。CI 限制最终 APK 小于 1 MiB，在 2 核/2048 MiB 的 Android 9 32 位运行时与 Android 14 64 位运行时上安装和启动，并测量 PSS 小于 128 MiB。实际包体积、内存与设备条件以 CI 产物为准，不能以设计目标替代实测。

默认主网直连、最低计算档位、单个工作线程。转发每次最多 4 KiB，响应上限 32 KiB，未处理的数据不落盘；不缓存书籍、附件或历史正文。没有 WebView、开屏资源下载、广告或网络探测。网络状态只读一次初始快照，随后使用系统默认网络回调与系统已有的 VALIDATED 状态；应用不自行发起验证网络的请求。

点击启用后使用可见的前台服务通知，通知和主界面均可停止。断网中止业务请求和计算，恢复后继续之前主动启用的任务；手动停止清除恢复意图。关闭界面保留通知。开机恢复默认关闭，必须由用户主动勾选；Android 或厂商限制启动时明确提示用户手动打开，不绕过权限。休眠、省电和厂商限制仍可能暂停任务，不承诺永久不被系统终止。

网络协作与计算接口复用奋斗页真实 API。客户端无管理员凭证、钱包或私钥；证明提交仍由服务器验证和原生共识决定，不把编译成功、传输字节或 HTTP 200 当作奖励。固定 HTTPS 目标、系统证书校验、禁止重定向和明文回退。直连不是匿名传输。

APK 使用独立、稳定保存的 Android 开发交付证书签名，不是 Play 商店审核或外部安全审计。私钥保存在私有部署密钥目录和 GitHub Actions Secrets，未进入源码、APK 或公开产物；以后升级须使用同一证书。安装时需用户批准来源；首次启动默认不助力、不自启。卸载交由系统移除服务、设置和程序数据。

所有 APK 编译和模拟器运行都交给 GitHub Actions；本地不执行 Android 或 ETP 重量级编译。工作流提供 SHA256SUMS、来源、签名证书信息、实际 UI/网络事件/内存证据。Android 9 在旧设备的系统证书需要保持有效，绝不关闭 TLS 验证来兼容过时系统。
